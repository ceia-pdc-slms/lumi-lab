# Adaptação e fine-tuning

Organizar protótipos e configurações por abordagem, compartilhando o código que for comum.

- **Decision:** pelo menos duas abordagens com mecanismos distintos de obter a decisão; comparar nos mesmos exemplos de desenvolvimento e registrar a escolha. Mudar somente o texto do prompt não caracteriza dois mecanismos.
- **Reasoning:** preparar dados em português, pipeline e treino curto até 19/11; concluir o primeiro fine-tuning até 26/11.

As variantes são experimentais e precisam declarar tarefas suportadas e limitações. Código e registros entram no GitHub; pesos/artefatos são publicados no Hugging Face.

Veja as [tarefas](../docs/tarefas.md), o [contrato](../docs/contrato-avaliacao.md) e a [publicação](../docs/huggingface.md). Nenhum treinamento foi executado nesta preparação.
