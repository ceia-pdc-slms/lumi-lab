# Notebooks

Guardar notebooks de inferência, protótipos, treinamento e avaliação das entregas, identificados pelo assunto e data. Cada notebook informa ambiente, modelos/dados com revisão, como executar e quais saídas foram efetivamente produzidas.

Chamar o código compartilhado de `benchmark/`, `adaptation/` e `adapters/`, evitando duplicar o avaliador em cada notebook. Preservar saídas úteis para a entrega, removendo credenciais e caminhos pessoais.

Materiais da fase 1 podem ser usados como referência com link e atribuição. Não apresentar resultados didáticos antigos como execução nova do benchmark Lumi. Veja as [tarefas](../docs/tarefas.md).

- [LumiBench](lumibench.ipynb) — duas trilhas sintéticas, execução local e recálculo idêntico.
